# chat-de-choco-tto

3分で終わる、チャット画面を操作する短編ゲームです。

`chat-de-choco-tto` という名前には、いくつかの語感を重ねています。

- `chat` : チャット画面そのものを触るゲーム
- `de` : 〜で、〜を使って遊ぶ感じ
- `choco-tto` : チョコ、ちょこっと、軽さ、かわいさ
- `noodle` の連想 : カップヌードルのような、短時間で一気に味が出るテンポ

`ヌードルゲーム` として出す想定で、少しヘンで、少しキャッチーで、短時間で終わる体験を目指しています。

## コンセプト

プレイヤーはチャット画面を直接操作します。

クリック、ドラッグ、並べ替え、入力、削除、伏字化、スタンプ差し替えのような UI 操作そのものがゲームプレイになります。

目指しているのは、普通の会話アプリを操作しているように見えるのに、実際にはそれが3分で終わるゲームになっている状態です。

## 方向性

- 1プレイは約3分
- 短くても印象に残るネタと展開を入れる
- チャット UI を触ること自体を遊びにする
- テキスト、通知、既読、スタンプ、入力欄などをゲームの仕掛けにする
- かわいさと妙さを両立する

## 世界観メモ

- `ちょこっと` は、軽さ、短さ、かわいさ
- `チョコ` は、甘さやポップさの方向
- `ヌードル` は、短時間で完成するテンポ感
- `ヌード` っぽい連想は、露骨な意味よりも「飾りが剥がれる」「本音が見える」「むき出しになる」演出として扱う

## ゲーム案の芯

チャット画面を操作して、会話や表示を変形させながらゴールを目指すゲーム。

たとえば次のような遊びを想定しています。

- メッセージの順番を入れ替える
- 伏字を外す、または伏字にする
- スタンプや絵文字を差し替える
- 入力候補やオートコンプリートを利用する
- 制限時間内に会話の流れを望む形へ誘導する

## 開発メモ

このフォルダは `Tauri + Vite + React + Tailwind CSS v4 + TypeScript` の最小ゲーム開発用プロジェクトとして初期化しています。

## セットアップ

```bash
npm install
```

## 開発

ブラウザでフロントだけ確認:

```bash
npm run dev
```

Tauri アプリとして起動:

```bash
npm run tauri dev
```

## ビルド

```bash
npm run tauri build
```

## 構成

- `src/` : React フロントエンド。今はチャットゲーム向けの最初の UI プレースホルダー入り
- `src-tauri/` : Rust / Tauri 側
